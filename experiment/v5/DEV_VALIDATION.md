- 새 검사기: 그 개발 세션에 `scripts/stream_response_validation.py`를 적용한 영수증은 `passed=true`. 정상 다중·단일 메시지, 스트림 조각 누락, 완료 텍스트 오염, 세션 최종 응답 불일치, 절단 완료의 6개 회귀 테스트가 통과했다.

## 새 후보의 검증

- `scripts.verify_v5_candidate_truth`: 16/16 과제 원문 답 재산출 통과. CSV의 채널별 합계, 설비 기준값, 네 등록 증빙 목록, 두 승인팀과 두 근거 부족 보류를 별도 검사했다. 초기 초안에서 `충전라인 누출 의심`의 조사와 검증 정규식 불일치 1건을 발견해 **동결 전에** 질문 생성기와 검사기를 수정했고 다시 16/16 통과했다.
- `scripts.validate_v5_tool_access`: 자료 4/4 검색, 문서 읽기와 CSV 표의 온라인 승인률 21/250 조회, 런타임 누출 검사 통과. 후보 과제의 정답이나 채점 정보는 Kiro 런타임 자료에 넣지 않았다.
- `scripts.v5_preflight --allow-draft`: 후보의 ID·질문·층화·단위·해시·자료 경로·v3/v4 문구 중복 검사 통과. 의미상 검토에서도 기존 지역 검수 불량률·영업일 에스컬레이션·고객 접수·책임팀 질문을 복제하지 않고, 새 반품 심사·설비 알림·관리 증빙·승인권한 원문과 사실값을 사용했다. 측정하려는 답 유형의 층화는 유지했다.
- v5 에이전트 프롬프트는 동결된 v4 텍스트와 바이트 단위로 동일하다. v4 출력 계약·채점·프롬프트 투영 코드를 변경하지 않고 v5 매니페스트의 해시 목록에 포함한다.

최종 회귀 테스트와 동결 결과는 상태 문서에 기록한다. 공식 Kiro 실행은 별도 사용자 지시 전까지 시작하지 않는다.
