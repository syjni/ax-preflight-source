# AX 3분 시연 리허설 카드

목표는 전체 기능을 설명하는 것이 아니라 `Readiness 100 → 반품 3/3 보류 → 충돌 문서 확인 → FAQ 수정 → 30일 3/3 직접 일치` 한 줄기를 3분 안에 끝내는 것이다.

현재 발화문은 공백 포함 651자다. 분당 300자 기준 약 130초이며, 화면 조작과 멈춤에 약 50초를 남겨 총 180초 안에 맞춘다. `python -m scripts.check_demo_timing`으로 다시 확인할 수 있다.

| 구간 | 화면 조작 | 반드시 말할 한 문장 | 종료 시각 |
|---|---|---|---:|
| 문제 | Before 요약 | “정적 Readiness는 100점이지만 실제 반품 업무는 세 번 모두 보류됐습니다.” | 0:25 |
| 진단 | 반품 충돌 Finding 펼치기 | “FAQ의 14일과 공식 정책의 30일이 충돌하고, AX가 두 문서와 조치를 지목합니다.” | 1:05 |
| 수정 결과 | After 전환, 반품 비교 표시 | “FAQ의 14일 문장을 제거한 뒤 반품 업무는 3/3 모두 30일이며 인용 응답과 값이 일치합니다.” | 1:45 |
| 정직한 범위 | After 요약·혼재 badge | “의미 비교 결과는 Before 5개, After 6개가 반복 안정이고 각각 2개는 혼재입니다. 전체 차이는 인과 개선으로 주장하지 않습니다.” | 2:20 |
| 차별점 | Evidence·관리자 1페이지 | “구조화 제출과 같은-run 근거만 저장하고, 관리자가 다음 검토 지점을 한 페이지로 받습니다.” | 2:50 |
| 마무리 | After 유지 | “AX는 AI 도입 전에 어떤 업무를 믿을 수 있고 어디를 먼저 검토할지 보여 줍니다.” | 3:00 |

## 중단 기준

- 1:10에 아직 Before 화면이면 세부 수치 설명을 생략하고 바로 After로 전환한다.
- 2:20 이후에는 35/60의 규칙 설명을 하지 않는다. 질문이 나오면 “직접 근거 일치이며 정답률은 아니다”라고 답한다.
- 관리자 리포트는 시간이 남을 때만 인쇄 버튼까지 보여 준다.
- 라이브 Kiro 실행은 하지 않는다.
